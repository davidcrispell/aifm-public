How to read the forecast

As AI takes on coding and chooses better experiments, it can speed up the research that improves the next model. Each line shows one trajectory under the selected assumptions. The dashed line appears when you move away from the baseline.

Coding speedup doubling time is the time it takes the extra coding productivity from AI to double near the calibration date. For example, a change from 20% faster to 40% faster doubles the gain.

Research judgment gain is measured in human standard deviations (SD) per progress-year. A progress-year is the capability gain from one year at the calibration date’s pace. If progress accelerates, that gain takes less calendar time.

The automated coder milestone requires full automation of an AI project’s coding work. The superhuman AI researcher milestone also requires experiment selection at the 99.9th percentile of human AI researchers.

The baseline uses the public model’s released reference parameters and input series. The model calibrates coding automation from observed productivity gains and simulates 2015–2050. The chart shows 2026–2030. The dates are conditional model outputs.

Fine adjustments run the Python model for values between the preset slider positions. On a static site, the first custom run downloads the Python runtime. BAIS model fork · Equations and assumptions
